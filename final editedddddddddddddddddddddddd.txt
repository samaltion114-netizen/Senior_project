7-مرحباً طارق،
يعطيك العافية، نريد إضافة ميزة (Business Rule) جديدة في الباك إند تخص تقييم الخبراء وتأثيره على مستواهم وسعرهم.
المطلوب هو تعديل الـ endpoint الخاص بتقييم الخبير: POST /api/experts/{expert_id}/rate/
بحيث عند إرسال تقييم جديد من الطالب، يتم تطبيق المنطق التالي في السيرفر:
حفظ التقييم الجديد وحساب متوسط التقييمات الجديد (average_rating) للخبير.
شرط التخفيض: إذا كان لدى الخبير 3 تقييمات أو أكثر، وانخفض متوسط تقييمه عن 3.5 نجوم:
تخفيض المستوى (expertise_level):
إذا كان senior ➔ يصبح certified
إذا كان certified ➔ يصبح junior
تخفيض السعر: تخفيض سعر الاشتراك الشهري (subscription_price) وسعر الساعة (hourly_rate) بنسبة 10% (أي ضرب السعر الحالي بـ 0.90).
حفظ التعديلات في قاعدة البيانات وإرجاع البيانات المحدثة في الاستجابة (Response).
💻 مثال مقترح لتطبيق المنطق (Python / Django or FastAPI style):
python
# عند استقبال التقييم الجديد
def rate_expert(request, expert_id):
    rating_value = int(request.data.get('rating'))
    
    # 1. حفظ التقييم الجديد في قاعدة البيانات
    Rating.objects.create(expert_id=expert_id, student=request.user, score=rating_value)
    
    expert = Expert.objects.get(id=expert_id)
    
    # 2. حساب المتوسط الجديد لتقييمات هذا الخبير
    ratings = Rating.objects.filter(expert_id=expert_id)
    avg_rating = ratings.aggregate(Avg('score'))['score__avg']
    expert.average_rating = avg_rating
    
    # 3. منطق تخفيض المستوى والسعر (إذا كان المتوسط أقل من 3.5 بعد 3 تقييمات على الأقل)
    if ratings.count() >= 3 and avg_rating < 3.5:
        if expert.expertise_level == 'senior':
            expert.expertise_level = 'certified'
            if expert.subscription_price:
                expert.subscription_price = round(expert.subscription_price * 0.90, 2)
            if expert.hourly_rate:
                expert.hourly_rate = round(expert.hourly_rate * 0.90, 2)
        elif expert.expertise_level == 'certified':
            expert.expertise_level = 'junior'
            if expert.subscription_price:
                expert.subscription_price = round(expert.subscription_price * 0.90, 2)
            if expert.hourly_rate:
                expert.hourly_rate = round(expert.hourly_rate * 0.90, 2)
                
    expert.save()
    
    # 4. إرجاع البيانات المحدثة ليعكسها التطبيق فوراً
    return Response({
        "success": True,
        "average_rating": expert.average_rating,
        "expertise_level": expert.expertise_level,
        "subscription_price": expert.subscription_price,
        "hourly_rate": expert.hourly_rate
    })
